## 先分清线路，再谈价格

CN2 是中国电信下一代承载网，AS4809，和普通电信 163 骨干网（AS4134）是两张网。它分两档：

- **CN2 GT**：只有国际出口段走 CN2，国内段还是挤在 163 里，晚高峰照样堵，体验和普通线路拉不开明显差距。
- **CN2 GIA**：全程强制走 CN2 节点，优先级最高，丢包最低，延迟最稳。日本独服报价里最贵的往往就是这几个字母。

去程和回程必须分开问。国内访问海外服务器，回程（服务器到国内）承载主要流量，回程走 CN2 GIA 的提升最明显。商家宣传页上写“CN2”，可能只是去程走、回程不走，也可能反过来。下单前问三句话：去程走什么、回程走什么、是不是双程 GIA。

按用户运营商选线路，规则很干脆：

| 你的用户以谁为主 | 优先线路 | 理由 |
| --- | --- | --- |
| 电信 | CN2 GIA | 三网回程优化，晚高峰丢包低，带宽贵、默认档位小（20M、40M 起步） |
| 联通 | 软银（SoftBank） | 联通方向速度甚至能压过 CN2，带宽成本低，套餐能给到 100M |
| 移动 | 软银或 CN2 GIA | 软银可用，GIA 更稳 |
| 日本本土及海外 | IIJ / NTT / 国际 BGP | 面向国内用户别选这类，延迟高、丢包不可控 |

一句话的取舍：要稳、要建站、要远程办公，选 GIA；要大带宽、要跑下载和推流、用户以联通移动为主，软银更划算。LightLayer 日本线路的具体走向，公开资料只提到有 CN2 与 Premium 线路可选，独服这一档到底接的哪条、去程回程分别怎么走，官网配置器上看不出来。

## 拿到测试 IP 后的四步验收

商家说什么是商家的事，你自己测一遍才算数。这套流程半小时能跑完。

1. **多地 ping**。用站长之家、itdog 这类工具，从国内电信、联通、移动节点分别 ping。日本 CN2 GIA 的电信方向正常在 50 到 90ms，丢包接近零；飘到 150ms 以上或明显丢包，基本不是真 GIA。
2. **traceroute 看路由**。Windows 敲 `tracert IP`，Mac/Linux 敲 `traceroute IP`，逐跳查 IP 归属的 AS。回程出现 `59.43.x.x` 段，就是 CN2（AS4809）节点，这是 GIA 的标志；只看到 `202.97.x.x`，那是 163 骨干，普通线路。
3. **下载测速文件**。找机房提供的 100MB 或 1GB 测试文件，从国内不同运营商下载，看能不能跑满标称带宽。独服的带宽理论上是独享，跑不满就是有问题。
4. **晚 8 到 11 点复测**。这是国内出口最堵的时段，也是线路含金量唯一有效的检验时间。晚高峰延迟翻倍、丢包飙升，白天测得再漂亮也没意义。

测完再付款。独服金额大，一次付一年动辄几千块，先拿测试机跑两天再决定，比事后扯皮省事。
